# Domínio próprio

Para servir a sua instância em um domínio seu, basta adicionar um registro DNS do tipo **CNAME** apontando
para o endereço da instância que será fornecido, e notificar a equipe de implantação para que façam os
ajustes necessários (certificado e configuração do site).
