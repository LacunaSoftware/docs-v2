# Temas disponíveis

Cada tema é identificado por um **código de três letras**. Esse código é o valor informado à equipe de
implantação para trocar o tema da instância, e também o valor aceito pelo parâmetro `theme` do widget
de [Assinatura Embutida](../../../apis/embedded-signature.md).

Além dos temas abaixo, existe o tema `default`:

![default](/images/signer/themes/default.png)
